🕷️ Spider XMD Ban Checker

Spider XMD is a Shell-based Telegram checker with a gateway layer. Send "/check +234XXXXXXXXXX" to validate a number and display available account-status information.

🚀 Setup

chmod +x *.sh
./install.sh
./bot.sh

Configure "BOT_TOKEN", "GATEWAY_URL", and "GATEWAY_API_KEY" before starting.
